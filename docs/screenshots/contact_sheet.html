QuMail 1.0 — Corporate UX Visual Contact Sheet

Pixel-rendered verification captures across all core views (Module 1.5 Workstream C). Verified authentic PyQt6 widget rendering.

1. Welcome Screen 800×600 · FIRST RUN
Design Evaluation:
  • Hierarchy: Centered brand shield ('Q' logo) with high-contrast title and call-to-action.
  • Copy: Business-oriented value proposition; zero cryptographic jargon.
  • Action: Clear primary action button guiding user to setup.
2. Onboarding: How It Works 620×520 · WIZARD STEP 2
Design Evaluation:
  • Educational Cards: 3 distinct pillars (Local Encryption, Cryptographic Verification, Honest Delivery States).
  • Clarity: Eliminates confusion about server delivery vs recipient decryption.
  • Navigation: Step progress counter and Back/Next navigation.
3. Permission Transparency & Connection 620×520 · WIZARD STEP 3
Design Evaluation:
  • Transparency: Explicitly discloses why IMAP PEEK and SMTP scopes are requested.
  • Security Hardening: Requires explicit confirmation before vault creation/unlocking; zero silent actions.
  • Safe Cancel: Clean cancellation without dangling background workers.
4. Main Email Workspace 1060×750 · INBOX VIEW
Design Evaluation:
  • Workspace Layout: Prominent top action bar, account switcher, and active status banner.
  • Search Bar: Real-time filtering by sender or subject.
  • Table Clarity: Clean columns (Status, From, Subject, Date, Security / Thread) with double-click opening.
5. Message Reader & Verification 1060×750 · READING PANE
Design Evaluation:
  • Truthful Verification: Clear panel showing signature validity, sender trust, and thread reference.
  • Readability: Distraction-free plaintext reading area with formatted headers.
  • Attachments: Verified attachment list with secure 'Save attachment as…' action.
6. Secure Compose Experience 900×800 · COMPOSE VIEW
Design Evaluation:
  • Truthful Indicator: Dynamic badge reflects true cryptographic state (e.g., 'Recipient Keys Verified').
  • Send Securely: One-click primary button automates Save → Prepare → Submit.
  • Data Safety: Retains user input on failure/unknown; close guard prevents accidental work cancellation.
7. Outbox Operations & Delivery States 900×800 · OUTBOX QUEUE
Design Evaluation:
  • Human-Readable Labels: Mapped states ('Accepted by mail server', 'Ready to send', 'Draft').
  • Auditability: Shows exact attempt count and durable transition reason.
  • Safety Controls: Disables automatic retries on UNKNOWN; requires explicit duplicate acknowledgment.
8. Account Identity & Settings 600×480 · SETTINGS
Design Evaluation:
  • Decoupled Lifecycle: Closing Settings does not lock the active mailbox session.
  • Transparency: Displays active Google email, root OpenPGP fingerprint, and vault path.
  • Key Management: Clear controls for contact pinning, key export, and certificate verification.

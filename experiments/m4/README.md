# M4 durable outbox development proof

Opt-in simulation only. No default application imports M4. No SMTP implementation,
real credentials, user-data migration or production MIME claims. ADR 005 permits
this work before live Google acceptance and independent review; neither is waived.

Use the existing M1 locked Python environment and M3 helper built with the exact
M2 Sequoia/OpenSSL inputs. No packages or native inputs are added. On the validated
Windows desktop logon session, from the repository root:

```powershell
./.venv-m1-clean/Scripts/python.exe -m experiments.m4.harness --simulate
./.venv-m1-clean/Scripts/python.exe -m experiments.m4.run_tests
./.venv-m1-clean/Scripts/python.exe -m experiments.m4.run_tests --reverse
./.venv-m1-clean/Scripts/python.exe -m experiments.m3.run_tests
$env:OQS_INSTALL_PATH = Join-Path $PWD 'tmp/oqs-install'
./.venv-m1-clean/Scripts/python.exe -m pytest -q
```

The harness creates only random disposable Windows Credential Manager entries
and a temporary database under ignored `tmp/`, generates separate sender/recipient
keys, uses explicitly synthetic identities, and deletes its entry in finally.
It demonstrates draft -> provider preparation -> committed submission intent ->
simulated interruption -> reopen/recover Unknown -> rejected implicit retry ->
explicit duplicate-risk retry -> simulated Accepted. It asserts exact bytes and
that an optional receipt failure leaves Accepted unchanged. No keys, plaintext,
token values or provider diagnostics are printed. Real abrupt process termination
is tested separately; the harness labels its interruption as simulated.

## Interfaces and state contract

- `model.py`: immutable operation, binding, envelope, credential/context handles,
  structured failures/results and Protocol interfaces; no Qt or network imports.
- `services.py`: PrepareMessage and SubmitOutbox ordering, retry, recovery,
  reconciliation and separate receipt export.
- `vault_adapter.py`: explicit M3 account transaction adapter; provider fixture
  builder receives a vault capability, not public API private-key bytes.
- `transports.py`: deterministic simulation; a non-simulation transport is rejected.
- `tests/crash_worker.py`: test-only child waits at specified boundaries; parent
  kills it without cleanup to exercise real SQLite/process restart behavior.

PrepareMessage.draft persists a protected draft and returns an opaque operation.
prepare requires the selected unlocked lease, active sender key and every verified
recipient. Only the exact experimental profile is accepted. The concrete provider
fixture supports one recipient; unsupported counts fail, not split or downgrade.
It returns raw standard OpenPGP bytes generated by the existing M3 provider. M5
owns full PGP/MIME and protected Message-ID/header integration; the stored stable
Message-ID is currently an outbox identity passed to the builder contract.

SubmitOutbox accepts only an existing operation ID. Submitting is committed before
transport; final acceptance is not recipient delivery. Interrupted or ambiguous
attempts are Unknown. `retry(..., acknowledge_duplicate_risk=True)` is an explicit
decision, not evidence of deduplication. Three attempts is the durable maximum.
Accepted cannot be retried. Reconciliation uses an injected observation, not a
resend. Never treat a local operation ID as SMTP exactly-once enforcement.

Use a fresh AccountAccess lease on selection/unlock and select(None) on lock.
Switching cancels the old lease. A result belongs to its original context; these
services never mutate a Qt display or select another account. Cancellation before
claim raises a structured error and leaves Prepared. Cancellation after committed
intent may require recovery to Unknown even when no transport was observed; that
conservative classification is intentional. An observed final acceptance remains
Accepted even if cancellation arrived after the side effect.

Draft/envelope/metadata/attempts are inside M3 account-authenticated encryption.
The archive references include certificate snapshots and the sender signing key;
they are not sender decryptability or a new wire archive format. Use only new
disposable development vaults. M3 backup restore does not remap these outbox IDs.

The repository holds a coarse SQLite writer transaction during simulation. It
serializes concurrent workers and recovery without unsafe timeout-based ownership
stealing. The adapter must honor its deadline/cancellation. Linux execution,
real SMTP TLS-before-auth, live OAuth mail scopes and production scheduling are
unvalidated. See the [acceptance table](../../docs/operations/m4-validation.md).
